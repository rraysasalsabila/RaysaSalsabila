# Raysa Salsabila — Personal Portfolio

A responsive pastel-style personal portfolio built with plain HTML, CSS, and JavaScript. It is ready to publish with GitHub Pages.

## Files

- `index.html` — page content and sections
- `style.css` — layout, colors, typography, and responsive styles
- `script.js` — mobile navigation, current year, and reveal-on-scroll effects

## Before publishing: personalize these details

Open `index.html` and replace:

1. `your.email@example.com` with your professional email address (it appears in the contact button and email link).
2. `https://www.linkedin.com/` with your LinkedIn profile URL.
3. `https://github.com/` with your GitHub profile URL.

You can also add real repository links to each project card once you decide which projects should be public. The current project cards are presentation-only and do not link to invented repositories.

Review all experience dates and descriptions before publishing. Add your profile photo if you want one; the current hero uses a typographic monogram so it works without a photo.

## Publish using GitHub Pages

1. Sign in to GitHub and create a new **public** repository.
2. For a personal site, name the repository exactly: `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root (not inside another folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish. Your website address will be `https://YOUR-GITHUB-USERNAME.github.io/`.

If you use a regular project repository instead, Pages will publish under `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`.

## Customize

- Change colors in the `:root` section at the top of `style.css`.
- Edit text, sections, and project details in `index.html`.
- Adjust navigation and scroll behavior in `script.js`.

No build step, package manager, or framework is required.
